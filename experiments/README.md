# 实验脚本

**这些不是产品的一部分，也不保证能跑。** 留着是因为它们记录了「试过什么」。

写进 README 会让人误以为能用，删掉又会让后来的人重新踩一遍同样的坑，
所以放这里：一段代码 + 一句结论，谁需要谁拿。

| 脚本 | 想解决什么 | 结论 |
|---|---|---|
| `subsync.py` | 用 VAD 重新对齐已有字幕的时间轴 | 有效但没必要。改成按时间预算切翻译单元之后，中文不再超预算，漂移自然消失 |
| `subchange.py` | 批量替换某几句译文并只重合成那几句 | 思路保留下来了，现在是 TTS 哈希缓存（`stages/tts.py`），改一句只重合成一句 |
| `voicelab.py` | 逐个试听音色、调语速 | 做进界面了（音色卡片带试听按钮） |
| `build_dialogue.py` | 手工把 transcript + 译文拼成 dialogue.json | 变成 `units.units_to_dialogue` |
| `speakers.py` | 按声纹区分说话人 | 没做成。pyannote 要 token、要额外 1.2GB 模型，且对播客里频繁插话的场景分得不准。多人音色仍在路线图上 |
| `batch.py` | 一次跑一批链接 | 变成网页的任务队列（串行、可取消、可重试） |

## 为什么单独放一个目录

它们都依赖旧版的目录约定（`scripts/common.py` 里的配置、`bin/` 里的 ffmpeg、
写死的输出路径），直接跑会失败。想复用请当作参考实现读，不要当作可执行文件。

真正的产品代码在 `src/videodub/`。两者不是同一套抽象，别混着改。
